Architecture Breakdown

1. ESP32 Edge Node

Equipped with an I2S microphone, this IoT node continuously captures surrounding environmental sounds directly at the source.

2. Audio Processing

The raw audio is converted into spectrograms or MFCC features. It filters out normal background noise to prepare for ML analysis.

3. ML Model Inference

A highly optimized, lightweight TensorFlow Lite model runs directly on the ESP32 microcontroller, avoiding cloud latency.

4. Event Detection

The system classifies the sound (e.g., Glass Break, Explosion, Crash) and assigns a confidence percentage to minimize false alarms.

5. Adaptive Routing

Alerts are sent through a smart mesh network. If an intermediary node is damaged or offline, the data automatically finds a new path.

6. Web Dashboard

The backend API securely receives the alert metadata and instantly updates this Web Monitoring Platform for immediate human action.
