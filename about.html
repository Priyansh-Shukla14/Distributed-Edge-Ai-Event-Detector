About the Project

Our distributed edge AI acoustic monitoring system places intelligent sensing directly at the source. Instead of sending raw audio to the cloud, our ESP32 IoT nodes process and classify sounds locally using optimized Machine Learning models.

This approach ensures real-time alert generation, preserves privacy, and significantly reduces network load. With our adaptive routing protocol, critical alerts seamlessly navigate the network and reach the web monitoring platform instantly.

Core Features

Real-Time Monitoring

Instantaneous acoustic analysis and classification for immediate threat detection.

Edge AI Inference

Neural networks and classification models running directly on microcontrollers.

Adaptive Routing

Self-healing network paths guarantee alert delivery even if an intermediary node drops.

Reduced Network Load

Only event metadata is transmitted (no heavy audio streams), preserving bandwidth.
